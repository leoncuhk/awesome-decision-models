The guide lists Edge/Lite, while the code whitelist additionally accepts Nano. These are implementation findings, not a model run or an independent reproduction.

The checkpoint builder filters `language_model.*` weights and constructs `Qwen3_5TextModel`; only token IDs enter its forward pass. It discards the image/video tower, so the text implementation does not establish a working multimodal training/export path. Optional training length caps can trim the state tail and must be evaluated separately. The research question is intent identification from domain images and contemporaneous dialogue, with evidence-insufficient clarification/handoff. Post-training is a means. Preregistered hypotheses connect papers to identifiability, residual adaptation, readout effects and shift tests; the primary endpoint is accepted-label coverage relative to the strongest frozen baseline under owner-defined consequential-risk/cost constraints, with intervals and per-class errors. The B0–B3 controls remain and a separate same-checkpoint continuation arm is conditional on verified image training support. No universal numeric pass threshold or expanded action-permission scope is introduced.
