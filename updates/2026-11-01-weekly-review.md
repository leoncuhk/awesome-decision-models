## Substantive changes

- **Drex Max v1**, within the existing Drex family: dense nominal 27B, fixed 255-code readout, noncausal full attention with causal linear layers, independent complete question rows. This differs from v2.0's text pointer model. [Fixed release](https://github.com/nace-ai/drex-decision-models/blob/e206b278e3988ad1b58e6f1556b559a65947a4e6/models/drex-max-v1/README.md), [HF repository snapshot](https://huggingface.co/nace-ai/drex-max-v1/tree/a67fa2808b5d91a4db62629beb14eba6d3f3e53c). CUDA images and text-only Mac paths are separate. Training overlap/calibration splits remain unknown; public Index aggregates do not substitute for private Full0.4. The release's evaluation date is Oct19, not this week's publication date. No new score/rank imported.
- **Keep the failed parity gate.** [Kapitsa's fixed Max notes](https://github.com/nace-ai/kapitsa/blob/dd1a80963dd36023a9889e26214030c2a98214c2/docs/drex-max.md) report maximum probability drift 0.0329, above their 0.02 gate, despite unchanged picks. Long-row reference parity/32k checks were not run; 128k/262k scratch allocations were excluded on 48GB before weights. The separate [Q4 card check](https://huggingface.co/nace-ai/drex-max-v1-affine-q4/blob/e7d0c597706239a015608c06dfe0951197e95096/README.md) has only 21 probability fields. Configured length, hardware fit, stable picks and calibrated decision quality are different findings.
- **Prism now supports Instant.** [Oct25 implementation](https://github.com/StartLuxLabs/StartLux-Prism/commit/cb700d0237ea37dad1772548f1f150dd4fc76b0b) adds v1.1 4B/9B/27B complete-row execution, without shared evidence/prefix cache or thought generation. Causal AutoThink remains separate. [Oct27 MXFP4 fix](https://github.com/StartLuxLabs/StartLux-Prism/commit/35d118d80dbe850d656efb409b2f475c84968e34) corrects a double-added residual that made answers batch-dependent. Internal invariance is not BF16 equivalence or probability calibration. These are runtime changes, not new model weights.
- **Strands compatibility and serving:** [pointer-only cleanup](https://github.com/strands-labs/strands-decider/commit/13c05149265dc404c09d2469636f71b1320e1713) retires obsolete slot configs; pointer was already current since v19. Frozen KL remains with an explicit trained pointer reference, precomputation and length grouping. [MLX worker fix](https://github.com/strands-labs/strands-decider/commit/13faf5214f7cbea07d005278f1aeaf3973611eba) keeps Gemma loading/execution on one thread. Neither establishes new weights or measured quality.
- **Jev coverage correction:** [models](https://docs.typesafe.ai/models) dates 1.14 to Oct14; latest/preview currently point to 1.14.0. This is a previously omitted release, not a new Nov1 checkpoint. Pin/log versioned IDs for tuned policies. [Image/Box docs](https://docs.typesafe.ai/images) explicitly describe experimental, below-production-standard behavior; the opt-in 262k context is slower/less accurate. Confidence remains distribution-derived. Hosted weights and exact evaluated snapshots are not public.

## New research, kept within task boundaries

[E37](../docs/evidence.md#e37), [Confidence Is Not a Promise](https://arxiv.org/html/2610.36311v1), studies selective-accuracy thresholds for Laya/Jev. Its 190 evaluations resample empirical populations, not independent deployments. LTT kept the nominal promise in those checks, but thresholds/temperature share calibration data, making the paper's construction approximate. Empty acceptance counts as kept; the Beta rule's extra coverage has no uniform guarantee. Fresh-item, language/noise/shift checks contain failures. Exact duplicates were filtered in Portuguese adaptation; near-duplicates and hosted training exposure remain unresolved. [Fixed README/datasheet](https://github.com/pcbrom/typed-deciders-audit/tree/8187f38fd4981f398d4e0e0d2291281ef5c58496) disclose withheld full Jev vectors/raw responses and some analyses. Third-party relative to model providers; not reproduced here, external archive not retrieved.

[E38](../docs/evidence.md#e38), [DFIP](https://arxiv.org/html/2610.36804v1), tests execution changes over existing checkpoints. Short resident native/DFIP ratios differ by workload/model; Liquid versus released compilation is essentially tied. Clef preserves picks while scores/confidence drift and serving pairs cross a 0.9 threshold. Diverse external arrivals reverse replay gains, with queueing, losses and retained CUDA failures. Author-reported optimization, not independent replication or billed savings. The [frozen analysis revision](https://github.com/superagent-ai/dfip/tree/f2eef1746e5e39b92827759344d4ef47410fc464) is distinct from per-trial execution commits. No model/checksum or runtime execution here.

[DICE](https://arxiv.org/html/2610.34124v1) adds a supervised candidate-recommendation baseline: candidate-isolated shared history, scoring head and separately fitted temperature/threshold. Its one target plus 19 sampled negatives, overlapping histories and possible pretraining exposure do not establish full-catalog retrieval or online utility. Estimated cascade costs omit routing overhead. Paper/methods/appendices reviewed; anonymous code not audited. No performance numbers imported.
