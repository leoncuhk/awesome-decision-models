# 企业决策模型后训练：当前判断与实施依据

核查日期：2026-11-19。目标是用企业数据改进有界语义判断，并以完整任务结果验收。**当前没有本次目标企业项目、数据或训练结果；本页给出研究角色与可证伪的选型规则，不宣布企业效果胜者。** 目标计算机为M5 Pro 48GB，未在该设备执行训练。

## 1. 当前结论：按部署目标选路线

| 部署合同 | 当前研究路线 | 依据与尚缺证据 |
|---|---|---|
| 读已有状态，要求零生成、低延迟 | 监督适配或推理到读出蒸馏；比较简单监督基线与SII／Kev等候选 | 有可查模型、训练与离线结果；尚无同一中文企业数据／预算下的胜者 |
| 运行时生成推理，再根据答案分布接受或转交 | PRDO与同底座生成式SFT／GRPO＋校准并列比较 | 四个小底座的知识选择题支持其概率质量和错误排序；数学验证有准确率退化，不能推成通用最优 |
| 同一状态需多个字段，或确有图像证据 | Intern及合适的多模态候选，逐字段、关系与终态分别验收 | 结构与训练实现可查；字段共用上下文不等于相互独立，图像推理不等于图像训练已验证 |

Nimble式最小事实改动、硬负例、缺证据和未知样本是**跨路线的数据因素**，不与底座或优化目标放在同一排行榜。校准和阈值是额外的部署步骤，也不等于更新模型权重。

这套规则保持稳定：新论文可改变某个条件下的证据与置信度；只有目标改变、来源纠错或匹配对照提供新结果，才改变相应候选的研究角色。单一榜单、可安装、内存较省或一个种子更高，都不足以替代领域验收。

## 3. 先定义企业判断，不先指定模型

输入是决策时可见的诉求、必要历史、已确认状态及来源时间、当前路径和候选条件。四项输出保留各自依据：[业务合同](domain-path-applicability-research.zh-CN.md)。

| 输出 | 应标注什么 | 确定性系统负责什么 |
|---|---|---|
| 路径适用性 | 相关／不相关、适用／不适用／证据不足；允许多路径及可替代答案 | 身份、资格、状态新鲜度与允许操作 |
| 信息充分性 | 缺哪项事实、证据在哪里、应查系统还是澄清 | 字段约束、取数来源与回执 |
| 冲突 | 事实、客户目标、政策或动作的具体矛盾 | 版本、显式互斥与退出规则 |
| 优先关系 | 前置依赖、并行、暂缓与撤销依据 | 依赖图、明确业务优先及客户顺序 |

模型适合判断自然语言条件是否得到证据支持；精确金额／日期计算、授权、状态组合和执行校验由代码与业务合同承担。路径相关、获准执行、动作完成和客户获益是不同终点。状态缺失、owner丢失、政策冲突或坏工具不能靠后训练可靠补出。

首轮选一个可重复的错误或成本瓶颈，例如遗漏必要路径、目标撤销后误触发旧流程，或简单判断占用昂贵调用。技能加载仅在漏载／无关上下文确实致败时另立对照；不同时更换判断器、加载方式、执行器和政策后把总增量归给一个模型。

## 4. 研究候选：职责明确，尚未选出企业胜者

| 研究角色 | 当前候选与具体产物 | 训练入口及条件 | 推荐强度 |
|---|---|---|---|
| 能力与蒸馏机制 | SII-Decision：4B基于Qwen3.5-4B；27B基于Qwen3.8-27B | 原始底座上的同尺寸分布蒸馏；发布训练器要求`gold_target`、教师`train_target`和原版`p0`。Gold虽非蒸馏目标，仍参与hard-Noul权重／评估；不是只有硬标签即可续训的入口 | 有理由优先研究其机制与公开能力；企业适配与Mac可运行性仍待验证 |
| 自有标签的可审查适配链路 | Kev：4B等adapter／pointer head；9B／27B作质量参照 | 有`--data`＋`--init_from`的领域适配，需同一问题和标签合同；中文、候选变化、服务与校准另测 | 适合研究直接领域适配；工程完整不代表4B准确率最高 |
| 多字段／视觉专项 | Intern-Decision-4B及匹配的模型／运行时 | 官方路线为CUDA／XTuner、冻结视觉部分并训练语言骨干；非现成Mac LoRA | 有明确结构用途，条件性纳入；不凭低ECE认定生产风险较低 |
| 证据边界的数据因素 | 开放Nimble-9B配方及对比数据构造 | 候选token监督／LoRA；旧开放9B与新托管v4／v4.1分开。模型许可与仓库代码许可分别核验 | 数据因素值得跨路线比较；未建立该构造相对其他同预算数据的普遍因果优势 |

当前同协议能力线索来自[JEVal v2表1](https://arxiv.org/html/2610.03935v2#S4.T1)：SII-4B／27B为71.92%／79.24%，Kev-4B／9B／27B为68.90%／70.87%／77.17%，Intern-4B为70.74%，Nimble-9B为73.87%。分母10938个choice/noul，准确率含失败。不同尺寸、训练暴露及作者基准限制都保留；SII是该基准作者提出的模型，这不是独立企业认证，也不代表当前所有同名版本。

[Jev](decision-model-posttraining-platform-audit.zh-CN.md)、PPLX、Clef等可作质量／部署对照，但托管可用、权重开放和可继续训练是不同资格。完整家族与训练产物矩阵见[平台核查](decision-model-posttraining-platform-audit.zh-CN.md)及[模型卡](models.md)。成本较低的分类器／encoder保留作必要基线；其硬件便利性不赋予质量优先级。

## 5. 用什么信号，才谈哪种后训练

| 数据与实际推理单位 | 合理基线／候选 | 关键约束 |
|---|---|---|
| 完整可信标签或可接受答案集合，部署直接判断 | CE／BCE、候选排序、必要时Brier项，独立校准 | LoRA／全参／只训头是参数化选择；不能与loss／底座同时改后做单因归因 |
| 可靠教师或思考后的分布，部署为单次学生读出 | soft CE／KL分布蒸馏；SII为可查例子 | 拟合教师不等于拟合业务真值；教师logit、重复采样频率和口述confidence不是同一种概率 |
| 部署保留一条生成推理，并按其后分布接受／转交 | PRDO逐推理proper-score目标，同底座生成式基线 | 主方法没有推理score-function奖励，共享权重仍更新；半梯度、KL和第二阶段分别解释，不能统称RLCD越多越好 |
| 只有所选动作的反馈 | 先审反馈语义、选择策略、支持与缺失，再研究CAPS等条件方法 | 金标模拟反馈不等于退款／转人工结果；业务策略价值与反事实识别另有要求 |

**当前证据的边界：**

- 监督学习是可靠标签任务的强基线，没有“CE必胜RLCD”的结论。Laya三seed公开面板的方向不稳定，见[配对核查](decision-model-posttraining-method-audit.zh-CN.md#7-同一laya内soft-ce与rlcd复算公开多种子结果)。
- PRDO在四底座知识选择题上改善Brier与AURC；数学验证可排序更好、准确率更差。它不直接替代零生成路由，也没有比较上表模型。SII固定教师均值蒸馏，与PRDO批评的“训练student混合、部署其单条推理”不是同一对象。[全文复核](decision-model-posttraining-method-audit.zh-CN.md#8-prdo-v2全文复核怎样改变当前路线)
- T只需为正；同题argmax一般不因单一正温度改变。温度不能修正全部错误排序，也不能创造缺失证据。NONE答案、概率校准、风险阈值与动作授权分别验收。
- 400步、4B拐点、250条标签、固定top-k或低于1pp均为局部设置／点估计，不能当跨任务规律。空输入、候选顺序、同义条件、缺事实、全错候选与新政策必须进入对照。

逐条数值、论文版本、负结果、公开预测复算及未知产物集中在[方法核查](decision-model-posttraining-method-audit.zh-CN.md)，当前建议只在本页维护。

## 6. 企业数据与验收：从案件到新版本

| 阶段 | 必须留存的材料 | 未满足时 |
|---|---|---|
| 问题与数据 | 当前系统、重复失败／成本、负责人、允许后果、数据权利与脱敏边界、路径／政策版本 | 继续诊断，不指定更大模型或新平台 |
| 状态与标签 | 决策前可见输入、未知字段、状态来源／时间、owner、已完成动作、支持证据、允许集合、禁止动作与终态 | 修定义或标unknown，不能把未来结果／未加载直接当当前输入／负例 |
| 基线与学习曲线 | 当前系统、简单监督／检索、强质量参考、原版与适配版；同状态／候选／执行器及匹配选择预算 | 先排除状态修复、候选差异和模板先验解释，不将汇总高分当增量 |
| 独立确认 | 冻结模型／schema／预算／回退策略后，在Test检验关键错误、覆盖、完整成本及配对区间 | 保留负结果；未显著不等于等价，是否扩展由价值与预算决定 |
| 影子与生产 | 全流量可抽样日志、回执和分歧；有界分流、停止／回滚及结果成熟窗口 | 不接管真实权限，不以离线或供应商报告替代客户完成结果 |

按客户、案件、会话、时间与来源分组，**先切分再做配对、翻译和改写**。Train更新权重，Dev选方法和预算，Cal-fit拟合温度，Cal-policy选完整接受／转交规则，Test只作冻结确认。若数据少而共享校准组，只报告探索性经验结果，不声称原独立校准风险证书仍适用。多候选共享案件，统计单位不自动变成独立决策。

自然流量或已知抽样权重用于总体风险／费用；困难例和少数高代价样本单列。既有人工选择、教师共识和最终处理结果都需核对标签依据。盲审模型分歧，也抽查一致样本；只审升级案件会漏高置信错误，只看已接受案件又漏被抑制的有效请求。

验收同时报告：路径／事实／字段的任务指标，关键误触发与漏判，完整任务正确完成和返工，NLL／明确口径的Brier／ECE，风险—覆盖及区间，检索＋取数＋判定＋重试＋工具＋人工的完整成本和p50／p95。低ECE、组件快或高top-1不单独构成采用条件。

## 7. 平台与硬件：先核可实施性

TypeSafe当前不提供客户权重微调；阿里是有准入／版本限制的托管LoRA；部分开放家族只公开权重／推理、缺原始训练材料。接口形状相似不保证鉴权、schema、tokenizer、字段隔离、概率及校准一致。[平台核查](decision-model-posttraining-platform-audit.zh-CN.md)

48GB统一内存的Mac与48GB独显＋额外主机内存不是同一资源条件。SII的4／8GPU训练wrapper、Intern的CUDA全语言参数训练、PRDO的全参及CPU offload都不能照搬；改成LoRA／MLX或另一底座是新的实现条件。先测代表性最长输入的真实前向／反向、有限更新、峰值与swap、导出重载、概率及判定一致性。[Mac准入与示例](decision-model-posttraining-mac-recipe.zh-CN.md)

## 8. 证据、置信度与改变判断的条件

| 当前判断 | 置信度与证据边界 | 怎样才会改变 |
|---|---|---|
| 不应以一个混合总榜决定企业后训练 | 高：任务、尺寸、语言、训练暴露、预算与风险目标均不同 | 有完全匹配且独立确认的领域比较后，可在该合同内排序 |
| SII／Kev值得保留为直接读出研究对象 | 中：公开能力与可查产物支持研究；不是同等成熟的企业训练入口，亦未选出胜者 | 相同案件、标签预算、质量门槛及全成本下的真实适配对照 |
| PRDO值得作为保留推理的选择性判断路线 | 论文设置内支持较强；中文企业／更大底座／Mac外推尚弱 | 原产物复算、目标机实现验收和独立领域结果，含准确率退化预算 |
| 最小事实改动与独立校准值得纳入实验 | 数据与测量因素合理；各增益需匹配消融，不作普遍成功承诺 | 对照能排除标签频率、表面捷径、教师偏差和阈值选择乐观偏差 |
| 当前企业底座、loss和生产收益已确定 | 未建立 | 真实企业数据及冻结对照先通过，再做影子和生产验证 |

供应商集成、作者离线报告、公开产物审计／复算、独立新推理／训练和生产对照分别记录。论文与同作者代码重复一个结论不算独立验证。观察到的新证据可修正判断；未经匹配的高分只能更新候选线索，不能自动改写当前采用建议。
